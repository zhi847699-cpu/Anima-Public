# Anima SkillPack Studio（公开源）

这里**只有**远程配置，没有源码、没有作者版、没有签发工具。

| 文件 | 用途 |
|---|---|
| `version.json` | 买家软件检查更新 |
| `licenses.json` | 扩展包开通码名单 |
| `creator.json` | 创作者名片和赞赏码 |

买家版 ZIP 只出现在 [Releases](https://github.com/zhi847699-cpu/Anima-Public/releases/latest)，不要把 ZIP 提交进 Git。

软件本体免费。扩展包需要卖家按本机开通码签发，并且把开通码写进 `licenses.json`。
