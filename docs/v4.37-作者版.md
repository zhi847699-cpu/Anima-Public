## 色裁流程（作者自测 / 出图）

1. 顶栏点「色裁」，打开「使用色裁二次创作」
2. 选角色（可上传立绘识别外貌；会锁定当前角色，避免和技能包角色串脸）
3. 选服饰颜色：角色签名色，或自定义主色 / 辅色 / 点缀；签名色下点角色色只给单件上色
4. 勾选服饰和细节（连体衣与上下衣互斥）
5. 左侧勾场景 / 镜头 / 姿势等其他提示词
6. 「发送到生图框」写入正向
7. 「补充提示词」按词库补空位，不改已选服装和勾选

组装工作台和生图页同样有「补充提示词」。关掉色裁开关后，本地组装完全走技能包。
