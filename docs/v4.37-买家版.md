# Anima SkillPack Studio v4.37 买家版

公开下载：[Anima_Buyer.zip](https://github.com/zhi847699-cpu/Anima-Public/releases/download/v4.37.0/Anima_Buyer.zip)

## 这版给你什么

软件本体免费。核心含安全向芯片、擦边词，以及 Illustrious / Pony / Animagine / SDXL / Flux 安全逻辑。成人向词库与其余模型逻辑是可选扩展包，需卖家按本机开通码签发。

## 色裁（开通内容包后）

1. 打开「色裁」页，打开「使用色裁」开关。关掉则生图完全走技能包勾选。
2. 选角色（会锁定外貌，不会串到左边以前勾的角色）。
3. 选服饰颜色：角色签名色，或自定义主色 / 辅色 / 点缀。签名色下点角色色只给单件上色，不会关掉签名色。自定义配色：先点栏位再点色块，再点同一色进入单件上色。
4. 勾选上衣、下衣、连体衣、配饰、细节。连体衣与上下衣互斥，避免一套里又旗袍又衬衫。
5. 左侧技能包再勾场景、镜头、姿势等。
6. 点「发送到生图框」：二次创作服装 + 当前勾选写入生图正向。发送按钮贴在页底，不用翻到最下面找。
7. 点「补充提示词」：只从词库补空位，**不会改你已勾的项和色裁服装原文**。

## 打开方式

- Windows：解压后双击 `START.vbs`（会生成本机开通码）
- macOS / Linux：双击「打开.command」

## 开通收费包

1. 用启动器打开，顶栏点「授权」，复制开通码发给卖家
2. 卖家签发绑定本机的加密授权文件，并把开通码和包 ID 写入 GitHub `licenses.json`
3. 回到「授权」页，导入卖家私信发来的加密文件（电脑和手机同一格式）
4. 文件验证 + GitHub 验证都通过后才会开通
