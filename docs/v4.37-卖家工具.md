# Anima 卖家工具 v4.37

私人仓 draft，禁止放进买家 ZIP 或公开 Latest。

文件：`Anima_Seller_Tools.zip`

## 里面有什么

- `issuer.html` 签发台（浏览器打开）
- 母版：`masters/content-adult.json`、`masters/logic-extra.json`
- 示例逻辑：`examples/irodori-logic.json`
- 启动：`START.bat` / `一键启动.bat` / `打开签发台.command`

## 签发步骤

1. 买家用 START 打开软件，在「授权」页复制开通码发给你
2. 打开签发台，选择内容包或逻辑包母版，填入开通码，生成加密文件
3. 把开通码和包 ID 写入公开仓 `licenses.json`（双重验证）
4. 加密 JSON 私信发给买家；买家在「授权」页导入

电脑和手机用同一份加密文件。不要把 `issuer.html`、母版 JSON、`pack-secret` 发到公开仓。

## 和色裁的关系

买家开通内容包后才会出现色裁页：选角色、服饰颜色、细节，发送到生图框，再按词库补充提示词。签发内容包即可解锁，无需另做色裁包。
